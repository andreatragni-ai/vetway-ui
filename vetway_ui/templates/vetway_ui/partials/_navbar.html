{% comment %} _navbar.html — cornice generica della barra di navigazione: voci desktop (da md in su), hamburger + offcanvas sotto md, area utente con logout. Nessun link e' cablato qui: le voci arrivano dall'ospite via variabili. Variabili attese: nav_voci — lista di dict, una per voce: url — href label — testo icona — classe Bootstrap Icons senza "bi-" (es. "search"), facoltativa attiva — True per evidenziare la voce corrente title — tooltip, facoltativo nav_sezioni — facoltativo, per l'offcanvas: lista di {label, voci} (stessa forma di nav_voci) mostrate sotto un'etichetta di sezione nav_menu_titolo — titolo dell'offcanvas (default "Menu") utente_label — testo accanto all'icona utente (es. user.username) utente_url — link del profilo utente, facoltativo utente_logo — URL di un logo/avatar, facoltativo logout_url — se valorizzato mostra il pulsante Logout (form POST con csrf) L'ospite che ha bisogno di dropdown o voci condizionate dai permessi sovrascrive direttamente il blocco `navbar` di vetway_ui/base.html con il proprio markup, riusando le stesse classi (.ovic-nav, .ovic-nav-hamburger, #navOffcanvas, .nav-section-label, .user-info). {% endcomment %}
