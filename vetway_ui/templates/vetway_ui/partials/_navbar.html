{% comment %} _navbar.html — cornice generica della barra di navigazione: voci desktop (da md in su), hamburger + offcanvas sotto md, area utente con logout. Nessun link e' cablato qui: le voci arrivano dall'ospite via variabili. Variabili attese (tutte facoltative; senza brand_* e senza figli il markup e' identico a quello della 0.1.0): brand_url, brand_label, brand_img — marchio a sinistra dell'hamburger (dalla 0.2.0): link, testo e/o immagine (URL). Compare se c'e' almeno brand_label o brand_img. nav_voci — lista di dict, una per voce: url — href label — testo icona — classe Bootstrap Icons senza "bi-" (es. "search"), facoltativa attiva — True per evidenziare la voce corrente title — tooltip, facoltativo figli — (dalla 0.2.0) lista di voci {url, label, icona, attiva, title}: a desktop la voce diventa un dropdown Bootstrap, nell'offcanvas un gruppo con etichetta di sezione (.nav-section-label) e le voci figlie sotto. La voce madre e' evidenziata se attiva lei o una figlia. Con figli, `url` della madre non serve. nav_menu_titolo — titolo dell'offcanvas (default "Menu") utente_label — testo accanto all'icona utente (es. user.username) utente_url — link del profilo utente, facoltativo utente_logo — URL di un logo/avatar, facoltativo logout_url — se valorizzato mostra il pulsante Logout (form POST con csrf) `nav_sezioni` della 0.1.0 e' stata tolta (nessun ospite la usava): faceva la stessa cosa dei figli ma solo nell'offcanvas, e a desktop le voci sarebbero mancate. Oggi una sezione = una voce con figli, in entrambi i casi. Nell'offcanvas l'ordine e': voci semplici, poi un gruppo per ogni voce con figli, nell'ordine di nav_voci. L'ospite che ha bisogno di piu' di questo sovrascrive direttamente il blocco `navbar` di vetway_ui/base.html con il proprio markup, riusando le stesse classi (.ovic-nav, .ovic-nav-brand, .ovic-nav-hamburger, #navOffcanvas, .nav-section-label, .user-info). {% endcomment %}
